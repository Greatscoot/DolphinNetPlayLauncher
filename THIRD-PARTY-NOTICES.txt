DOLPHIN NETPLAY LAUNCHER - THIRD-PARTY NOTICES
==============================================

Dolphin Emulator
----------------
Dolphin NetPlay Launcher is an unofficial frontend that works with a user's
existing Dolphin installation. Dolphin is not bundled with this project and
Dolphin NetPlay Launcher is not affiliated with or endorsed by the Dolphin
Emulator project.

SDL3
----
Controller input uses SDL3. Build.bat downloads the official Windows x64 SDL3
runtime when SDL3.dll is not already present and preserves SDL's accompanying
license as SDL3-LICENSE.txt when available.
